WHAT WAS ACTUALLY CHANGED IN CODE
================================================================================

Only ONE file was modified for the actual fixes:
  → middleware/netlify-db-service/src/routes.js

All changes follow these patterns:

1. Added middleware imports at top:
   import { authenticateToken, authorizeRole, 
            verifySelfOrAdmin, verifyInstallationOwnershipOrAdmin }

2. Added authenticateToken middleware to endpoints:
   router.get('/endpoint', authenticateToken, async (req, res) => { ... })

3. Added role-based authorization:
   router.get('/endpoint', authenticateToken, authorizeRole('admin'), async (req, res) => { ... })

4. Added ownership/self checks in handlers:
   if (!verifySelfOrAdmin(req, res, targetUserId)) return;
   if (!await verifyInstallationOwnershipOrAdmin(req, res, installation)) return;

5. Added query parameter validation:
   if (userId && userId !== req.user.id && !isAdmin) { return 403; }

THE 7 FIXED ISSUES (Quick List)
================================================================================

1. ✅ GET /api/installations/:id
   - Was: No auth required
   - Now: Requires auth + ownership check

2. ✅ GET /api/users
   - Was: No auth, exposes all users
   - Now: Admin/superadmin only

3. ✅ GET /api/users/:id
   - Was: No auth, exposes any profile
   - Now: Requires auth + self/admin check

4. ✅ GET /api/users/:userId/installations
   - Was: No auth, enumerates any user's installations
   - Now: Requires auth + self/admin check

5. ✅ POST /api/users
   - Was: No auth, anyone can create users
   - Now: Admin/superadmin only

6. ✅ GET /api/installations/*/monitoring|performance|maintenance
   - Was: Auth only, no ownership check
   - Now: Requires auth + ownership check

7. ✅ GET /api/installations
   - Was: Can bypass with userId query param
   - Now: Validates userId param against authenticated user
