QUICK REFERENCE COMMANDS
================================================================================

Start PostgreSQL:
  export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"
  pg_ctl -D ~/.postgres -l ~/.postgres.log start

Start API Server:
  cd middleware/netlify-db-service
  npm start

Stop PostgreSQL:
  export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"
  pg_ctl -D ~/.postgres stop

Test API:
  curl http://localhost:3001/api/users

Connect to Database:
  export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"
  psql -h localhost -U apolaki_user -d apolaki_db
