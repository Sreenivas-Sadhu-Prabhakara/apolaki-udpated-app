## 🎯 Configuration Quick Reference

**Environments:** Development | Staging | Production

- **Dev:** [.env.dev](../config/env/.env.dev) - Local development setup
- **Staging:** [.env.staging](../config/env/.env.staging) - Pre-production testing
- **Prod:** [.env.prod](../config/env/.env.prod) - Production deployment

**Database & Services:** [docker-compose.yml](../config/docker-compose.yml)

Services included:
- PostgreSQL 15 (Database)
- Redis 7 (Cache & Sessions)
- RabbitMQ 3.12 (Message Queue)
- Elasticsearch 8.11 (Search & Analytics)

**Database Schema:** [init-db.sql](../config/init-db.sql)

Includes:
- User authentication & OAuth providers
- Solar installations & performance metrics
- Analytics & trading data
- Chat messages (Viber/Telegram)
