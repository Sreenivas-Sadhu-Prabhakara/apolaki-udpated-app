===============================================================================
SECURITY MIDDLEWARE STACK
===============================================================================

authenticateToken
  - Verifies JWT token validity
  - Validates user exists and is active
  - Attaches user to request

authorizeRole(...roles)
  - Checks if user has required role
  - Returns 403 if insufficient permissions

verifyInstallationOwnershipOrAdmin(req, res, installation)
  - Admin/superadmin: Always allowed
  - Regular users: Must own the installation

verifySelfOrAdmin(req, res, targetUserId)
  - Admin/superadmin: Can access any user
  - Regular users: Can only access own data
