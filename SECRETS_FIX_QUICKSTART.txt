OPTION A: FORCE PUSH (Fast, if you're alone)
================================================================================

1. Rotate Your Credentials FIRST:
   
   Google OAuth:
   - Go to: https://console.cloud.google.com/
   - APIs & Services → Credentials
   - Delete old OAuth credentials
   - Create new ones
   - Copy new Client ID and Secret

2. Force push the cleanup commit:
   
   cd /Users/macstudio/Documents/Code/apolaki-udpated-app
   git push --force-with-lease origin main

3. Update local .env:
   
   cd middleware/netlify-db-service
   # Edit .env - replace PLACEHOLDER values with new credentials
   GOOGLE_CLIENT_ID=YOUR_NEW_ID
   GOOGLE_CLIENT_SECRET=YOUR_NEW_SECRET

4. Test:
   
   npm run dev

OPTION B: GITHUB UNBLOCK (Safe for teams)
================================================================================

1. Rotate Your Credentials FIRST:
   
   Google OAuth: https://console.cloud.google.com/
   Facebook: https://developers.facebook.com/apps/
   AWS: https://console.aws.amazon.com/iam/

2. Click the unblock links GitHub provided:
   
   - For Google OAuth Client ID
   - For Google OAuth Client Secret
   
   These confirm you've rotated the credentials

3. Push the cleanup commit:
   
   cd /Users/macstudio/Documents/Code/apolaki-udpated-app
   git push origin main

4. Update local .env with new credentials:
   
   cd middleware/netlify-db-service
   # Edit .env - replace PLACEHOLDER values

5. Test:
   
   npm run dev

CRITICAL: ROTATE CREDENTIALS IMMEDIATELY
================================================================================

⚠️  IMPORTANT: The old credentials were visible in git history!
    You MUST invalidate them on Google/Facebook/AWS immediately.

1. Google OAuth:
   https://console.cloud.google.com/apis/credentials
   → Delete old credentials
   → Create new ones

2. Facebook (if applicable):
   https://developers.facebook.com/apps/

3. AWS (if applicable):
   https://console.aws.amazon.com/iam/
   → Delete old access keys
   → Create new ones

⏰ Time limit: Do this within 1 hour of discovering the exposure

COMMON ISSUES
================================================================================

Q: Push still fails after force push?
A: Make sure you:
   1. Rotated credentials on Google
   2. Waited 1-2 minutes for GitHub to refresh
   3. Used correct command: git push --force-with-lease origin main

Q: How do I test locally with new credentials?
A: Edit middleware/netlify-db-service/.env
   Replace: GOOGLE_CLIENT_ID=PLACEHOLDER_REPLACE_LOCALLY
   With: GOOGLE_CLIENT_ID=YOUR_NEW_ID_FROM_GOOGLE
   Then: npm run dev

Q: Can I share the old credentials?
A: NO! They're compromised. Don't use them anywhere.
   Always generate new ones.

Q: What if multiple people push?
A: Use Option B (GitHub Unblock) instead of force push.
